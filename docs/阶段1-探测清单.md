# 阶段 1 探测清单（装好环境后第一步做）

> 目的：在写任何自动化代码之前，先用 ADB 手工验证「语音厅的控件树能不能读」。
> **这个结果直接决定走技术方案 A（控件定位）还是 C（图像识别）。**

---

## 前置：确认 ADB 可用

雷电模拟器自带 ADB。默认端口通常是 `5555`（多开时不同实例端口不同）。

```bash
# 1. 找到雷电自带的 adb（安装目录下）
#    典型路径：D:\leidian\LDPlayer9\adb.exe

# 2. 连接模拟器
adb connect 127.0.0.1:5555
adb devices          # 应看到 127.0.0.1:5555  device

# 3. 若显示 unauthorized：在模拟器里允许 USB 调试
```

---

## 探测 #1：控件树是否可读 ★ 最关键

```bash
# 在语音厅任意界面（建议先进一个房间），执行：
adb shell uiautomator dump /sdcard/ui.xml
adb pull /sdcard/ui.xml ./ui_dump.xml
```

打开 `ui_dump.xml` 看：

| 观察 | 含义 | 结论 |
|---|---|---|
| XML 里有大量 `<node>`，含 `text=` `resource-id=` | 标准安卓控件 | ✅ **走路线 A** |
| XML 几乎为空，或只有一个大 node、无文字无 id | 自绘 UI（游戏引擎/Flutter/Skia） | ❌ **路线 A 破产，转路线 C** |
| 有 node 但 `text` 全是空、`resource-id` 全是空 | 半自绘，无辨识特征 | ⚠️ 只能靠坐标，脆弱 |

**把 `ui_dump.xml` 发给我，我来判断。**

---

## 探测 #2：关键控件有无稳定标识

在 dump 出的 XML 里搜这些关键词，看有没有对应的 node：

| 界面 | 找什么 | 期望 |
|---|---|---|
| 主界面底部 | 「消息」「我的」等 tab 的 text | 有 text 就能点 |
| 搜索页 | 搜索输入框 `EditText` | 有就能 `send_keys` |
| 会话页 | 输入框、「发送」按钮 | 有就能自动发 |
| 房间内 | 表情/礼物按钮 | 有就能打call |
| 房间内 | 「欢迎」按钮 | 有就能自动欢迎 |

**记录下每个关键控件的 `resource-id` 或 `text`**，这就是未来的「控件映射表」。

---

## 探测 #3：搜索定位目标用户

手工在语音厅里搜一个用户 ID，观察：
- 搜索结果列表长什么样
- 能否直接点进会话
- 搜索框是原生 `EditText` 还是自绘

```bash
# 搜索页 dump 一次
adb shell uiautomator dump /sdcard/search.xml
adb pull /sdcard/search.xml
```

---

## 探测 #4：登录态能否保持

1. 登录语音厅 → 完全关闭 App → 重新打开 → 是否还在登录态？
2. 重启模拟器后再看一次。

**若频繁要求重新登录 / 弹验证码**：说明风控较严，需要额外方案（保活、人工兜底）。

---

## 探测 #5：发送后的界面回显

手工发一条消息，观察：
- 气泡是否出现？是否带发送状态（发送中/已送达）？
- 时间戳是否更新？

**这是安卓端"送达确认"的唯一依据**（因为没有 CDP 的 messageUId）。

---

## 探测 #6：模拟器检测/风控

- 语音厅是否提示"检测到模拟器"？
- 是否有异常环境告警？

若有，需要在模拟器里做设备指纹伪装（改 IMEI/机型）。

---

## 采集到的信息怎么用

把以下内容发我，我据此确定方案：

1. **`ui_dump.xml`**（探测 #1 的产物）—— 决定路线 A 还是 C
2. 关键控件的 id/text 列表（探测 #2）
3. 登录态是否保持（探测 #4：是/否）
4. 是否有模拟器检测（探测 #6：是/否）
5. 语音厅版本号、模拟器型号/分辨率

## 附：常用 ADB 命令速查

```bash
adb connect 127.0.0.1:5555              # 连接
adb devices                             # 列出设备
adb shell uiautomator dump /sdcard/ui.xml   # dump 控件树
adb pull /sdcard/ui.xml .               # 拉取到本地
adb shell input tap X Y                 # 点击坐标
adb shell input swipe X1 Y1 X2 Y2       # 滑动
adb shell input text "hello"            # 输入文字（英文/数字）
adb shell am start -n 包名/Activity      # 启动 App
adb shell pm list packages | grep sybl  # 找包名
adb exec-out screencap -p > shot.png    # 截图
adb logcat | grep -i sybl               # 看日志
```

> 中文输入：`adb shell input text` 不支持中文，需要装 ADBKeyboard 输入法或用剪贴板注入。
> 这是后续要解决的一个小问题，先记着。
