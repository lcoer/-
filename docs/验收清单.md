## 待真实设备验收

| 场景 | 操作与期望 |
| --- | --- |
| 桥接升级 | 在软件中主动安装/启用 APK，确认协议 v2 已就绪；不兼容时明确提示 |
| 真实采集 | 进入明确房间，读取真实记录；未知 UID、性别、公会保持未知；停止后不再入库 |
| 私聊身份 | 指定测试 UID 与完整昵称，对方主页 UID 相符才允许输入；不相符无发送 |
| 文字输入 | 中文、emoji、长文字与残留输入；输入不一致禁止点击发送 |
| 发送确认 | 使用一条明确测试文字，最多一次；界面确认不宣称服务器送达 |
| 失败/断线 | 发送后断线或取消归为待确认；重启仍不自动重发 |
| 任务协调 | 启动中、运行中、停止中启动另一个任务都提示占用；停止后再放行 |
| 欢迎/打call | 只操作已确认入口；无入口跳过，不切换为文字发言 |
| 长时间运行 | 选定房间运行至少 30 分钟，检查重入、内存、日志与停止 |
| 安装与升级 | 新目录安装、旧配置兼容、用户数据保留、APK 签名兼容 |
| 分辨率 | 默认分辨率之外验证滚动、弹窗和控件定位，不凭离线树宣称兼容 |

真实发送需要指定测试对象 UID、昵称、文字和次数。未提供测试对象时默认只进行离线、隔离渲染和只读设备验收。
